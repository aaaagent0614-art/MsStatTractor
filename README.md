# MsStatTractor（楓之谷練功追蹤 HUD）

一個給「新楓之谷：經典版」用的練功輔助工具。它用 OCR（光學文字辨識）直接讀取**畫面上**的 LV／HP／MP／EXP 與楓幣數字，幫你追蹤每一段練功的經驗值變化、HP/MP 損失、楓幣增減，以及每分鐘效率與升級預估時間。

**只會「看」畫面，絕不會點擊、輸入或對遊戲送出任何操作，也不讀取記憶體或遊戲檔案。**

---

## 下載與安裝

**⬇️ [直接下載最新版（MsStatTractor-latest.zip）](https://github.com/aaaagent0614-art/MsStatTractor/releases/latest/download/MsStatTractor-latest.zip)**

或點這裡看 [GitHub Release 頁面](https://github.com/aaaagent0614-art/MsStatTractor/releases/latest)（所有版本、更新紀錄）。

1. 解壓縮下載的 zip，得到一個 `MsStatTractor` 資料夾。
2. 雙擊裡面的 `MsStatTractor.exe` 即可，**不需要安裝 Python 或任何東西**。

> 資料夾要**保持完整**（執行檔需要旁邊的檔案才能運作），可以整個放到任何位置，例如 `桌面\MsStatTractor`。

> 首次執行時 Windows 可能跳出 SmartScreen 警告（因為執行檔沒有數位簽章），點 **更多資訊 → 仍要執行**。

## 操作手冊

### 第一步：按「辨識」確認有抓到遊戲

開啟程式後，先按儀錶板頂部的「**辨識**」按鈕，確認程式有正確抓到遊戲畫面：

1. 開好楓之谷（新楓之谷：經典版），視窗保持在前景、不要最小化。
2. 雙擊 `MsStatTractor.exe`，切到「**儀錶板**」分頁。
3. 點頂部的「**辨識**」按鈕，等一下看結果：

| 結果 | 意思 | 怎麼做 |
| --- | --- | --- |
| 偵測到 **4/4** 欄位 | 成功抓到狀態列 | 可以直接開始記錄 |
| 偵測到 **3/4** 欄位（缺 MP） | 少抓一個欄位 | 再按一次「辨識」通常就好 |
| 偵測失敗 | 沒抓到 | 把遊戲視窗拉回前景、取消最小化，再按一次 |
| 偵測到 4/4 欄位＋楓幣 | 狀態列＋楓幣都抓到 | 完美 |
| 偵測到 4/4 欄位，請開啟道具欄（I） | 楓幣沒抓到（道具欄沒開） | 開道具欄後再按一次辨識 |

> 按「辨識」後，LV／HP／MP／EXP 的**原始數據會直接顯示**在儀錶板上（不再是 `--`），方便確認每個欄位都有抓到。若某個數字 OCR 讀錯，**直接點擊該數字**即可手動輸入正確值（輸入框留空並確定＝恢復自動讀取）；下次按「辨識」會重新抓取並清除手動值。

> 程式用的是 Windows 圖形擷取（WGC），直接抓遊戲視窗自己的畫面——所以**就算其他視窗疊在遊戲上、或開著 Magpie 放大，都讀得到**，不用管遮擋。

### 第二步：點擊輸入地圖

1. 在儀錶板找到「**地圖**」欄位，會顯示「**＋ 點擊輸入地圖**」。
2. 點它，輸入你目前所在的地圖名稱，按確定。
3. 名稱會**自動保存**，之後每一段紀錄卡片都會帶上地圖名稱，方便比較不同練功點的效率。

### 第三步：開始記錄

- 按「**開始**」開始追蹤。畫面會即時更新 LV／HP／MP／EXP、經驗值變化、升級預估時間等。
- 按「**暫停／繼續**」暫停（暫停期間不計入變化，但畫面仍持續讀取）。
- 按「**停止**」結束這一段，進入「待結算」狀態（可接著記錄賣裝收益，見下方）。
- 按「**重新開始**」提前結束目前這一段、存檔後立刻開下一段。

> 開始後主視窗會縮小成一個**置頂小視窗**，顯示 HP 消耗、MP 消耗、楓幣收入、經驗值變化與升級預估時間，並提供「暫停／停止／還原」按鈕。停止後主視窗自動還原。小視窗拖曳到的位置會記住，下次開啟仍在原位。

### 楓幣追蹤（選用）

1. 在設定開啟「**楓幣追蹤（道具欄）**」（預設已開）。
2. 按「開始」後，按 **I** 開一次道具欄（程式讀取楓幣當起始值）。
3. 結束前再按 **I** 開一次道具欄（當結束值）。
4. 兩者相減就是這段時間「**楓幣掉落**」的增減（花錢會顯示負數）。

#### 賣裝收益（把掉落的裝備算進這段收益）

掉落的**裝備**要賣商店才有楓幣入帳，而賣裝通常發生在結束之後。程式支援把這筆錢補記回「剛才那一段」：

1. 按「**停止**」結束記錄後，畫面會出現「**記錄賣裝**」按鈕（這段紀錄先不存檔）。
2. 去商店把裝備賣掉，然後按 **I** 開道具欄。
3. 按「**記錄賣裝**」→ 程式讀取賣裝後增加的楓幣，記成「**賣裝收益**」，**並立刻把這段紀錄存進「紀錄」分頁**（不用等下一段開始）。
4. 該筆紀錄的「楓幣」會分成**野生楓幣**（打怪掉的）與**裝備＋掉落物**（賣裝收益）兩行顯示。

> 若結束後沒有要記錄賣裝就直接按「開始」，會跳出「尚未計算裝備收益，是否開始新的紀錄？」——選「是」就直接存檔開新段。

### 歷史紀錄

- 切到「**紀錄**」分頁。
- 每段紀錄一張卡片：起訖時間（**直接顯示實際時長**，如「4.6分」）、經驗值增減、HP/MP 損失、楓幣變化（**分成野生楓幣與裝備＋掉落物**）、EXP/分效率、地圖名稱。
- 可點卡片標題**重新命名**、**刪除單筆**、或**清空全部**。
- 紀錄會自動保存到資料夾，重開程式仍在。

### 比較功能（兩筆紀錄互相比效率）

1. 切到「**比較**」分頁（第四個分頁）。
2. 用兩個下拉選單分別選「**紀錄 A**」和「**紀錄 B**」（選單會顯示紀錄名稱／編號＋開始時間）。
3. 下方表格自動列出兩筆的**時長、地圖、經驗值、經驗/分、HP 損失/分、MP 損失/分、楓幣/分、野生楓幣、裝備+掉落物**，最右欄顯示「A 比 B」的差異百分比（綠色＝A 較好、紅色＝A 較差）。

> 比較頁只看已保存的紀錄；隨時可以換選單重比，刪除紀錄後選單會自動更新。

### 藥水成本／淨收益（參考巴哈「經驗值計算器」）

練功的開銷主要是藥水。到「**設定**」分頁的「藥水成本」區，輸入你喝的：

- **HP 藥水單價** 與 **每瓶恢復 HP**
- **MP 藥水單價** 與 **每瓶恢復 MP**

設定後，儀表板會顯示「**藥水成本**」（依消耗量估算）與「**淨收益**」（楓幣收入 − 藥水錢）。全部留 0 則不顯示。

**用快捷鍵藥水數量精準計算（2026-09-03）**：如果藥水放在快捷鍵欄上，可以用「實際消耗瓶數」：

1. 到「設定」→「**快捷鍵藥水**」，分別選「**HP 藥水在第幾格**」和「**MP 藥水在第幾格**」（快捷鍵共 8 格：上排 Shift／Ins／Home／PgUp，下排 Ctrl／Del／End／PgDn）。
2. 位置預設**自動偵測畫面右下角**；若你的快捷鍵欄在別處，按「**標記快捷鍵欄位置**」拖曳框選整排。
3. 儀表板的藥水卡會顯示各藥水的**位置**與**目前數量**（持續偵測，約每 5 秒一次）；開始記錄時讀一次、結束再讀一次，消耗瓶數 = 開始 − 結束，藥水成本直接用 瓶數 × 單價。
4. 若格內數字因 UI 太窄顯示不全，讀數會不準（當約略值）；中途補水會讓消耗被低估。

> 儀表板已移除「HP 損失／MP 損失」顯示（由藥水數量取代）；「**賣裝收益**」與「**淨收益**」要按「記錄賣裝」之後才會算出數值（之前顯示 `--`，因為賣裝前淨收益不準）。

## 設定說明

| 分區 | 項目 | 功能與使用說明 |

| 視窗 | 視窗縮放 | 固定 **120%**（不可調整），文字大小已最佳化。 |
| 視窗 | 永遠置頂 | 讓 HUD 一直蓋在遊戲畫面上方，方便邊玩邊看。 |
| 視窗 | 語言 | 中文／英文即時切換。 |
| 設定 | 紀錄區間 | 每段紀錄多久自動重置，滑桿可調 **1～60 分鐘**（預設 10）。 |
| 設定 | 顯示 HP／MP | 個別開關 HP、MP 數值與進度條。 |
| 設定 | 顯示經驗值 | 顯示經驗值（**累計值**，升等後不會歸零）。 |
| 設定 | 顯示經驗值百分比 | 經驗值旁加掛目前等級的百分比。 |
| 設定 | 顯示升級預估時間 | 依目前效率估算距離升級還有多久。 |
| 設定 | 顯示預估本次經驗值 | 依目前效率推估這段紀錄結束大概拿多少經驗。 |
| 設定 | 計時結束時自動停止 | 預設開；時間到會停止並進入「待結算」（可記錄賣裝收益）。關掉後時間到直接接著開始下一段。 |
| 設定 | 重新開始時儲存至紀錄 | 預設開；關掉後按「重新開始」只捨棄進度、不留紀錄。 |
| 設定 | 紀錄結束時提醒（音效） | 結束時播放系統提示音（預設關）。 |
| 設定 | 楓幣追蹤（道具欄） | 開關楓幣追蹤（預設開），用法見上方「楓幣追蹤」。 |
| 手動 | 使用手動標記的位置 | 切換到手動標記模式（見下方「手動標記模式」）。 |
| 手動 | 標記狀態列位置 | 拖曳紅框框住遊戲左下角的 LV／HP／MP／EXP 那一條。 |
| 手動 | 標記楓幣位置 | 拖曳紅框框住道具欄的楓幣數字。 |

## 手動標記模式（備援，一般不需要）

預設的**自動模式**已經能抗遮擋、支援 Magpie，多數情況不需要手動標記。手動模式留作備援，當自動模式在某些特殊環境讀不到時使用：

1. 切到「設定」→「手動設定位置」→ 開啟「**使用手動標記的位置**」。
2. 點「**標記狀態列位置**」，拖曳紅框框住遊戲左下角顯示 LV／HP／MP／EXP 的那一條。
3. （要追楓幣）再點「**標記楓幣位置**」，框住道具欄的楓幣數字。
4. 回儀錶板按「開始」。

> 標記位置會**自動保存**，下次開啟不用重標。位置跑掉時，按「辨識」重新抓取即可。

## 系統需求

- **Windows 10 1803 以上**（建議 Windows 11）。
- 安裝並執行中的楓之谷（新楓之谷：經典版）。
- **建議解析度 1366×768 以上**，視窗越大文字越清楚、辨識越穩定。

## 疑難排解

- **辨識一直失敗** — 確認遊戲視窗在前景、沒有最小化；關掉再開一次遊戲視窗試試。
- **所有欄位顯示 `--`** — 通常是遊戲視窗不在前景（楓之谷失去焦點會降低畫面更新）。把遊戲視窗點一下、按「辨識」重抓。
- **HP／MP 損失看起來不太對** — 請當作大概數字，不是精確統計：程式每秒讀兩次，同一個間隔內扣血又補回的部分看不到；OCR 偶爾誤判會灌進假損失。經驗值沒有這問題（只取「結束減開始」，讀錯會自己修正）。
- **楓幣顯示 `--`** — 需要開始後、結束前各開一次道具欄（I），兩者都有了才會算出變化。
- **數字偶爾停一兩秒才動** — 正常：讀錯的那一幀會被丟掉、沿用上次數值，寧可慢半秒也不要顯示錯誤數字。
